# OxideDNS Specification Documents

This directory contains the documents provided by Tibor Dravecz in the email titled `OxideDNS Secondary DNS Server Softver Development Specification`, dated 2026-05-23.

The email says the SDS and SBVR material are normatively subordinate to the SRS v0.1. If documents disagree substantially, implementation work should follow the SRS and update the companion documents afterward.

## Files

- `OxideDNS-Secondary-SRS-v0.1.md`: primary normative Software Requirements Specification.
- `OxideDNS-Secondary-SBVR-v0.1.md`: SBVR Structured English companion specification.
- `OxideDNS-Secondary-SRS-v0.1-Executive-Summary.md`: executive summary.

- `source-exports-removed/`: removed source exports, including DOCX/PDF/ZIP files.
