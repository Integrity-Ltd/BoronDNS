# Appendix A — Requirements Traceability Matrix

This matrix maps the [SRS](BoronDNS-Secondary-SRS-v1.0.0.md) requirements to
tests, capture tools, and retained reports. It is an evidence index, not a
statement that every requirement has passed full acceptance.

`BDS-VER-008` defines the public-beta milestone. The broader evidence gaps
below concern future full SRS acceptance unless a row says otherwise.
Historical Alpha/v0.2 results retain their original scope. See the
[ledger](verification-ledger.md) for an overview and the
[gap register](release-acceptance-gap-register.md) for the active queue.

## Status Values

- **Not Verified**: no accepted evidence is recorded.
- **Partial**: evidence exists but does not cover the full listed scope.
- **Verified**: cited evidence covers the stated scope.
- **Deferred**: verification is assigned to a later milestone.

A script/source pointer identifies where a behavior is checked; it is not a
record that a particular release passed. Pending project decisions remain
pending until explicitly resolved. Preserve exact SRS IDs and same-prefix
ranges so the coverage checker can detect omissions.
