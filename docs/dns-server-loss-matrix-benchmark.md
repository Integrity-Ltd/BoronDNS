# DNS Server Loss Matrix Benchmark

This benchmark compares OxideDNS, Knot, and NSD on the dedicated two-host
physical link. It records both ordinary UDP socket rows and AF_XDP rows where
the server supports them.

Run the forward direction with:

```sh
OXIDEDNS_PHYSICAL_DETACHED_HARNESS="$PWD/scripts/physical-dns-server-loss-matrix.sh" \
scripts/physical-udp-detached-batch.sh start
```

The default forward direction is:

- server: `OXIDEDNS_PHYSICAL_SERVER_SSH=oxidedns-1`
- player: `OXIDEDNS_PHYSICAL_PLAYER_SSH=oxidegun-1`
- target IP: `198.18.0.1`
- source IP: `198.18.0.2`

Run the reverse direction after the forward run finishes:

```sh
OXIDEDNS_PHYSICAL_SERVER_SSH=oxidegun-1 \
OXIDEDNS_PHYSICAL_PLAYER_SSH=oxidedns-1 \
OXIDEDNS_PHYSICAL_TARGET_IP=198.18.0.2 \
OXIDEDNS_PHYSICAL_SOURCE_IP=198.18.0.1 \
OXIDEDNS_PHYSICAL_SOURCE_MAC=1c:34:da:60:67:00 \
OXIDEDNS_PHYSICAL_TARGET_MAC=b8:59:9f:4b:73:2c \
OXIDEDNS_PHYSICAL_DETACHED_HARNESS="$PWD/scripts/physical-dns-server-loss-matrix.sh" \
scripts/physical-udp-detached-batch.sh start
```

The matrix wrapper enables:

- `OXIDEDNS_PHYSICAL_INCLUDE_KNOT=true`
- `OXIDEDNS_PHYSICAL_INCLUDE_KNOT_XDP=true`
- `OXIDEDNS_PHYSICAL_INCLUDE_NSD=true`
- `OXIDEDNS_PHYSICAL_INCLUDE_NSD_XDP=true`
- `OXIDEDNS_PHYSICAL_OXIDEDNS_UDP_BACKENDS="std af_xdp"`
- `OXIDEDNS_PHYSICAL_PLAYER_TOOL=oxide-gun`
- `OXIDEDNS_PHYSICAL_XDP_MTU=1500`
- `OXIDEDNS_PHYSICAL_PLAYER_MTU=1500`

The retained raw result is `summary.tsv`. The detached runner also writes
`loss-bands.tsv`, generated by:

```sh
scripts/summarize-physical-loss-bands.py summary.tsv
```

The loss-band summary reports the best row for each target at allowed requester
loss percentages `0`, `1`, `2`, `3`, `5`, and `10`. Keep the raw `summary.tsv`
for detailed rate-by-rate analysis; use `loss-bands.tsv` for high-level
comparison statements.

NSD notes:

- The source-built NSD path is `/home/codex/nsd-xdp-recvmmsg/sbin/nsd`.
- NSD's bundled XDP object redirects UDP destination port 53, so NSD XDP rows
  use `OXIDEDNS_PHYSICAL_NSD_XDP_PORT=53`.
- NSD XDP attach on the current 25G NIC requires MTU 1500. The harness restores
  the original MTU during cleanup.
